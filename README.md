# TacMap

에어소프트 서바이벌(밀리터리 시뮬레이션) 팀을 위한 **전술 상황 공유 안드로이드 앱**.

무전기만으로는 "좌익이 털렸는지, 어디가 밀렸는지"를 알 수 없습니다. TacMap은 전투 중에 화면을
흘끗 보는 것만으로 전선 상황이 파악되도록 만든 상황판입니다.

> 강원 인제 KCTC 도시지역 훈련장에서 열리는 민간 점령전 대회에서 15명 팀이 쓰려고 만들었습니다.

---

## 화면

가로 모드 전용. 폰을 플레이트 캐리어에 장착하고 쓰는 것을 전제로,
지도를 최대한 넓게 쓰고 조작은 좌우 세로 패널에 몰아두었습니다.

```
      [HQ 3/3  좌익 2/5  중앙 4/5  우익 3/4  미배정 1/1  사망 4/15]
                    ┌── 알림 오버레이 ──┐
 ┌────┐                                            ┌───────┐
 │사망│              Ⓐ  ← 거점(WoT 스타일)         │127° 남동│
 │3초 │         🏠좌익 ← 리스폰                     │지도 변경│
 ├────┤              ┼ 십자선                       │내 위치 │
 │ 적 │        ●독수리▲ ← 팀 색 + 시선 방향         │경기장  │
 ├────┤              ⊗ 사망지점   ☠ 적표식          │기준점  │
 │거점│       ╌╌╌ 경기장 경계 ╌╌╌                   │필드설정│
 └────┘                                            └───────┘
```

## 기능

### 전선 상황 파악 (핵심)
- **팀별 생존 요약 바** — `좌익 2/5` 형태. 절반 이하로 줄면 빨갛게. 전체 사망 카운터도 함께
- **사망 지점 핀** — 누가 어디서 당했는지 5분간 표시. 적 화력 위치를 역산할 수 있음
- **시선 방향 부채꼴** — 각 팀원이 지금 어느 쪽을 보고 있는지. 팀킬 방지와 경계 배치에 사용
- **팀원 명단 시트** — 생존/사망, 나와의 거리(m), 몇 초 전 위치인지, 최근 상황 로그

### 실시간 위치 공유
- 2초 주기 전송, 팀 색 마커 + 콜사인
- 30초 이상 갱신이 없으면 마커를 흐리게 (음영지역 표시)
- **포그라운드 서비스** — 디스코드 등 다른 앱을 앞에 띄워도 위치 전송이 끊기지 않음

### 점령전
- **거점** — 월드오브탱크 방식(색 링 + 문자). 아군/적군/중립을 누구나 토글
- **팀 리스폰(베이스) 지점**
- **경기장 경계** — 어드민이 꼭짓점을 찍어 다각형으로 설정
- **필드 프리셋** — 대회 전에 잡아둔 거점·리스폰·경계 배치를 저장해두고, 당일 새로 만든 방에 그대로 적용

### 적 표식
- 화면 중앙 **십자선 + 버튼** 방식 (뛰면서 지도를 정확히 탭하는 건 불가능)
- 적 / 저격 / 위험 / 집결 4종
- 60초 후 서서히 사라짐 — 오래된 적 위치는 오히려 판단을 흐리므로

### 전투 중 사용성
- 장갑 낀 손을 전제로 한 대형 버튼
- **사망 처리는 3초 홀드** — 진행률이 차오르고 완료 시 진동
- 알림은 상단 중앙 오버레이 (하단 버튼을 가리지 않음)
- **진동 패턴 구분** — 아군 사망 = 짧게 1회 / 거점 상태 변경 = 길게 2회. 화면을 안 봐도 인지 가능
- 화면 항상 켜짐
- 확대할 때 지도가 돌아가지 않도록 핀치 회전 비활성화. 회전은 나침반 버튼으로만

### 지도
- 배경 지도 5종 전환: **등고선(기본)** / Esri 위성 / 구글 위성 / 구글 위성+지명 / 일반지도
  - 국내 포털은 군사지역을 가려서, 해외 타일 소스를 골라 쓸 수 있게 했습니다
- 경기장 프리셋(A/B) + 좌표 직접 입력
- 나침반 방위 표시, 북쪽 고정 ↔ 진행방향 위 전환

### 방 / 팀 관리
- 회원가입 없음 — 콜사인만 입력하면 익명 인증으로 참가
- 6자리 코드로 방 참가
- 기본 팀 4개(HQ / 좌익 / 중앙 / 우익), 방장이 팀 추가·삭제
- 팀 배정, 콜사인 변경, 강퇴
- 인원이 다 안 차도 언제든 게임 시작 가능

## 기술 구성

| 영역 | 선택 | 이유 |
|---|---|---|
| 앱 | Flutter (Dart) | 단일 언어로 UI·지도·위치·통신. APK 빌드가 단순 |
| 서버 | Firebase **Realtime Database** | 서버 코드 불필요. 전송량 과금이라 고빈도 위치 갱신에 적합 (Firestore는 쓰기 건당 과금이라 15명 × 2초면 무료 한도 초과) |
| 인증 | Firebase Anonymous Auth | 전투 직전에 회원가입 화면을 띄울 수는 없음. 그래도 서버에서 "누가 썼는지"는 구분해야 하므로 uid는 필요 |
| 지도 | flutter_map + 교체 가능한 타일 소스 | API 키·과금 없이 무료 범위에서 운영 |

### 데이터 구조

```
/rooms/{6자리코드}
  meta          : 방장 uid, 상태(lobby|live|ended)
  teams/{id}    : 이름, 색, 순서
  members/{uid} : 콜사인, 팀, 방장 여부
  live/{uid}    : lat, lng, 정확도, 방위각, 시각, 사망여부   <- 고빈도 쓰기라 분리
  markers/{id}  : 적 표식 (클라이언트가 시간으로 걸러냄)
  objectives/{id}: 거점 (이름, 좌표, 소유)
  spawns/{teamId}: 리스폰 지점
  boundary      : 경기장 경계 좌표 배열
  events/{id}   : 사망·복귀·거점 변경 -> 알림과 사망 핀이 같은 데이터를 씀

/presets/{id}   : 대회 전에 저장해둔 필드 배치 (거점·리스폰·경계)
```

**설계 포인트**
- `live`를 `members`에서 분리 — 위치가 2초마다 바뀌어도 팀 명단 화면이 다시 그려지지 않음
- 표식 소멸은 서버 삭제가 아니라 시각 기준 클라이언트 필터 — 서버 함수가 필요 없어 무료 등급 유지
- 권한은 보안 규칙으로 서버에서 강제 — 방장이 아닌 사람이 남의 이름을 바꾸거나 강퇴하려 하면 앱이 아니라 서버가 거부

## 빌드

Flutter SDK와 Android SDK가 필요합니다. 최소 지원은 **Android 7.0 (API 24)**.

```bash
flutter pub get
flutter test
flutter build apk --release
```

Firebase 설정 파일(`lib/firebase_options.dart`, `android/app/google-services.json`)은
저장소에 포함하지 않습니다. 직접 쓰려면 본인 Firebase 프로젝트를 만들고
[FlutterFire CLI](https://firebase.google.com/docs/flutter/setup)로 생성하세요.

```bash
firebase projects:create <프로젝트id>
flutterfire configure --project=<프로젝트id> --platforms=android
firebase deploy --only database   # database.rules.json 배포
```

Realtime Database와 익명 로그인을 Firebase 콘솔에서 사용 설정해야 합니다.
